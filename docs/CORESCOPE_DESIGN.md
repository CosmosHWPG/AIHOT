# CoreScope 行业与界面设计

本机版本面向移动核心网通信设备供应商及 AI 领域的技术主管、专家、架构师、技术洞察、标准、安全、战略与商业规划团队。品牌使用 CoreScope / 核心网与 AI 技术洞察。

## 阅读结构

沿用 AIHOT 的暖白纸面、墨色文字、青绿色强调色、暗色主题、桌面侧栏和移动底部导航。保留精选时间线、全部动态、事件热点榜、日报/周报/月报、主题目录、收藏和模型榜的大页面结构。主题数与文章数由 API 和数据库提供，空主题保持真实空状态。

- **精选**：每日重点，保留摘要、阅读价值、出处、评分与事件后续。
- **全部动态**：搜索及按类别、标签筛选，适合证据核对和补充阅读。
- **事件热点榜**：保留上游独立主体、48 小时窗口、24 小时半衰期与趋势规则。榜单说明明确限定为本站监测范围。
- **技术主题**：先按技术与决策问题浏览，再按实际主体公司/标准组织和内容形态进入长期积累。
- **报表**：延续上游分节、真实条目引用、历史归档与日报报纸版式，报头采用 CoreScope 自有“洞察日报/周报/月报”字样。
- **模型榜**：保留供 AI 能力与选型研究。关闭与目标读者关联较弱的 Codex 额度重置监控。

精选与全部动态新增“全部 / 核心网 / AI / 交叉”入口。交叉使用 `tag=核心网&topic=ai`，公开读取层把核心网标签与仅含 AI 标签的主题条件做 AND，要求文章同时属于两个领域；不能将两标签放进 topicTags 误用 OR。其他入口使用单个真实 `tag`，保持类别、一手筛选和搜索参数，翻页状态在切换时清除；没有在浏览器里伪造数据。主题目录的领域视角筛选配置好的目录项，通用研究、工程、商业和政策主题可覆盖两个领域。单个公司主题仍以实际主体为归属条件，提及不等于主体。

## 分类和主题

保留现有六个类别 key：`ai-models`、`ai-products`、`industry`、`paper`、`tip`、`opinion`，以及七种 itemType。调整显示文案与 guide，让产品包含网络能力、产业包含标准及安全通报、工程包含网络和 AI 架构实践。避免迁移已有 URL、RSS 与测试契约。

领域词表新增核心网、AI、5GC、6G、标准/协议、云原生网络、网络安全、网络智能化、网络开放/API、专网/边缘、网络韧性，以及 AI 记忆、评测、安全、基础设施和商业/战略。“AI商业”单独标记 AI 的商业事实，避免主题按任一标签匹配时将全部 AI 内容收入商业主题。内容理解提示词与 taxonomy 白名单同步。`DOMAIN_TAG_RULES` 只让独占技术标签补充领域，通用标准、云原生、安全、部署标签及公司名称不推断领域；归一化应保留结构与写作输出中已有的显式领域标记。

配置共 73 个主题、32 个主体。通信新增 Ericsson、Nokia、华为、中兴、Samsung、Cisco、Oracle、Red Hat，以及 3GPP、ETSI、IETF、GSMA、TM Forum、O-RAN Alliance、CNCF、NGMN、ITU。身份词典与发布方域名用于约束标题摘要不虚构公司或机构，原有主体抽取仍要求当前材料实际讨论该主体。

## 编辑口径

预筛宽召回核心网或 AI 的实质内容，不要求同时涉及两个领域；无法确定的材料保持 UNKNOWN。提供两个领域的工程、能力、标准、安全及商业价值示例，保留原有双评分、五维权重表和各信源门槛，未凭主观调整数字。是否选得准仍需用真实标注样本持续校准。

写作与归组保留规范编号、网元、接口、版本、适用范围、对照环境与发生阶段。标准提案、工作项目、Stage 1/2/3 冻结与规范发布分别表述，实验、试点与商用分别表述；不同规范、Release 或客户部署不能只因同公司或同“6G”主题合并。厂商给出的 TCO、ROI 和性能主张保留提出者与条件，不自行推导收益。导入原文完整性未确认时，后端在预筛、结构、评分与写作输入中显式注明，不能把残缺资料当完整正文。

术语口径对照以下主源，配置不硬编码当前版本的发布时间或冻结状态：

- [3GPP 新成员说明：Release 与各阶段冻结](https://www.3gpp.org/ftp/information/presentations/Newcomers_quick-start/Newcomers_slides.pdf)
- [ETSI NFV 技术组：云原生网络功能、基础设施与管理编排](https://www.etsi.org/technical-groups/nfv/)
- [GSMA Open Gateway API definitions：CAMARA 与接口成熟度](https://www.gsma.com/solutions-and-impact/gsma-open-gateway/gsma-open-gateway-api-descriptions/)

## 品牌与本机页面说明

导航标记、SVG、PNG/ICO 图标与报头均使用 CoreScope 自有几何图形或文字。软件保留上游 MIT 许可及 AIHOT 框架署名。使用规则和隐私说明按本机部署事实编写，说明原文版权、模型服务请求、浏览器收藏、服务端反馈与日志处理。

## 验证

行业配置校验：主题标签均属于词表或合法主体标记；内容理解白名单覆盖全部主题词；通信主体身份正则可识别真实名称。

界面验证：`npm run typecheck -w @aihot/web`、`npm run build -w @aihot/web` 和 32 项 web 测试通过（含交叉领域生产 SSR 回归）。完整系统验收还需由运行协调者检查真实模型分析、领域标签筛选、主题公开精选、事件归组与榜单、报表引用、移动/暗色布局和所有主要页面。
